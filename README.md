# 🍽️ Restaurant Catalog 
### Описание проекта 

Restaurant Catalog  — это онлайн-платформа, которая предоставляет пользователям возможность: 

Изучать каталог ресторанов с подробной информацией о каждом заведении.    
Бронировать столики в выбранных ресторанах.    
Следить за новостями ресторанного мира и гастротрендами.   
Оставлять отзывы и оценивать рестораны.   
     
### Требования
Для работы с проектом вам понадобятся следующие зависимости: 

- Python
- Django
- Docker
- Docker Compose 
- Git 
     
### Установка и запуск

#### 1. Клонирование репозитория:    
Склонируйте репозиторий на ваш локальный компьютер:    
    ```git clone https://github.com//MrRuzal/restaurant-catalog.git```    
    ```cd restaurant-catalog```
   
#### 2. Запуск с помощью Docker:    
a) Создание **.env** файла    
Скопируйте пример `.env` файла и настройте его под свои нужды: 
```cp src/backend/.env.example src/backend/.env```
    Отредактируйте .env файл, указав необходимые параметры (например, базу данных, секретный ключ и т.д.).    
    
b) Запуск контейнеров     
    Запустите проект с помощью Docker Compose: 
    ```docker-compose up --build```
    После успешного запуска приложение будет доступно по адресу: `http://127.0.0.1:8000`.  
    
c) Миграции и создание суперпользователя     
Выполните миграции и создайте администратора для Django Admin:     
```docker-compose exec backend python manage.py migrate```    
```docker-compose exec backend python manage.py createsuperuser```

#### 3. Локальный запуск (без Docker):    
Если вы хотите запустить проект без Docker, выполните следующие шаги: 

a) Создание виртуального окружения     
```python -m venv venv```
```source venv/bin/activate```  
  На Windows: ```venv\Scripts\activate```

b) Установка зависимостей     
```pip install -r src/backend/requirements/dev.txt```

c) Настройка переменных окружения    
Создайте `.env` файл в директории `src/backend/ `и укажите необходимые параметры из **.env.example**. 

d) Применение миграций      
```python src/backend/manage.py migrate```

e) Запуск сервера    
```python src/backend/manage.py runserver```    
Приложение будет доступно по адресу: `http://127.0.0.1:8000`. 

### Основные функции

#### Рестораны:
Просмотр списка ресторанов.    
Подробная информация о каждом ресторане (история, концепция, кухня).    
Рейтинги и отзывы пользователей.
    
#### Бронирование:
  
Возможность забронировать столик в выбранном ресторане.
Отслеживание статуса бронирования (ожидает подтверждения, подтверждено, отклонено).

#### Новости и тренды:

Публикация новостей о ресторанном мире.    
Информация о гастротрендах.
